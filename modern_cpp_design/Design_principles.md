Modern design principles

1. Favour composition (has-a) over inheritance(is-a)
    - low coupling, easier maintenance, better scalability
2. Program to Interfaces, not implementation
3. Prefer compile time polymorphism when possible
4. Use run time polymorphism only when needed
    - Ex. Device drivers, Plugins
5. Single responsibility principle
6. RAII everywhere
7. Prefer value semantics
8. Minimize Dynamic allocation
9. Open for extension / Closed for modification
10. Dependency injection
11. Hide implementation details (PImpl idiom)
12. Strong types




Modern C++ design patterns

1. Policy based design
2. CRTP
3. Strategy Pattern
4. std::variant + Visitor Pattern 
5. Type Erasure (Allow runtime polymorphism without inheritance)
6. Factory Pattern
7. Abstract factory
8. Observer Pattern
9. RAII
